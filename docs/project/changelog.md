# 项目模块变更记录

## 2026-10-16

- 项目/子项目删除、成员降级与移除接入SOP引用保护；成员列表返回owned_sops。部署新版前需安装SOP表，交接SOP负责人走独立SOP owner接口并写既有项目记录。
- 完成成员列表/候选、添加/重新加入、查看编辑权限变更、移除、项目及子项目负责人转移、操作记录接口；有效成员检查接入全部原项目授权路径。写操作复核当前管理权，保护负责人、校验版本，与记录同事务提交。
- 子项目资料编辑不再允许负责人变化；完成/归档状态允许独立人员交接。部署前需要执行002迁移，旧客户端转移负责人需切换专用owner接口。
- 新增项目/子项目restore接口及can_restore标志；按负责人范围和恢复权限校验，带version，事务恢复归档前状态并保留独立归档子项目。部署前需执行数据库001_archive_restore迁移。
- 第一批接口：项目与子项目增删改查、状态、归档和排序；创建项目自动加入创建人及负责人，校验项目范围、编辑权限与version。成员维护和主项目负责人转移尚未开放。
- 项目说明从Server/PROJECT-MANAGEMENT.md归入docs/project/README.md，前端页面细节改为引用前端仓库。迁移只调整文档位置和链接，不改变接口。

后续行为变化同步更新README.md，并在此简记兼容影响。

## 2026-10-16 SOP使用关联

- 项目/子项目增加SOP固定版本接口，变更关联递增目标及父项目version。
- 接口、授权与验证见[SOP后台文档](../sop/README.md)，本批不修改项目表。

## 2026-10-16 自动业务编号

新建项目/子项目/SOP由后台生成编号，旧编号保留。启用前执行公共流水表增量脚本001_business_code_sequence.sql，不重建业务表。前端不再提交code，接口文档已更新。


## 2026-10-16 自动编号MySQL兼容修复

- 流水字段last_value统一加反引号，修复MySQL 8.4建表及后台编号SQL的1064错误；字段名不变，无需重建成功建好的流水表。

## 2026-10-16 切换前端编号

采用前端类型前缀＋17位时间戳＋6位随机码，表单初始化一次、失败重试沿用；后台恢复接收code并只校验保存，移除流水服务与Mapper。旧编号及业务表保留，流水表不再是依赖，不执行删表。更新请求契约与回归测试。


## 2026-10-16 编号缩短到分钟

新编号采用PRJ/SUB/SOP-12位年月日小时分钟-6位大写随机码，移除秒和毫秒。前端生成、后台校验与测试同步更新，旧编号保持可读可编辑，数据库无迁移。旧流水服务及Mapper已删除，现有编号工具和业务异常类仍在用。
